# Contest Problem Solutions

This repository is a collection of solutions for competitive programming contest problems.

## Purpose

It is meant for organizing, storing, and reviewing solutions written during contests and practice sessions.

## What You Will Find Here

- Problem solutions in C++
- Organized notes and code for different contest rounds
- A simple space to track progress and improve problem-solving skills
- Companion `.md` files documenting each solution

## Solution Documentation

Each C++ solution (e.g., `contest-1112/alwaysChanging.cpp`) may have a matching markdown file (e.g., `contest-1112/alwaysChanging.md`) in the same folder with the same name, containing:

- **Problem Statement** - a summary of the problem's input, output, and constraints
- **Time / Space Complexity** - computed from the code instead of the raw time limit
- **Solution** - a brief, to-the-point explanation of the approach
- **Variables** - a pointwise explanation of the key variables used in the code

These notes make it easier to review and understand each problem later.

## Notes

- This repository is intended for learning and practicing competitive programming.
- Solutions can be added and updated over time as new problems are solved.
